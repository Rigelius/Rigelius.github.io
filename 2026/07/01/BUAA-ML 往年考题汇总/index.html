分类器性能度量

本2025 题1

写出混淆矩阵，解释 TP、FP、TN、FN 的定义。给出预测值和真实值，计算查准率、查全率和 F1 值。

研2023 题1

给出一个混淆矩阵。

  1. 说明 TP、FP、TN、FN 的含义。
  2. 计算 Precision、Recall 和 F1 值。

研2024 题2

写出混淆矩阵，解释 Precision 和 Recall 的计算方法，说明查准率、查全率两个指标之间的关系，并给出 F1 度量的计算公式。

研2024 题3

介绍线性分类模型、Fisher 准则、感知机准则、最小二乘准则、逻辑回归和支持向量机的基本思想，并说明支持向量机与一般线性分类器的区别。

贝叶斯决策

本2021 题2

基于最小错误率和最小风险进行贝叶斯决策。

本2023 题1

题干给出先验概率和决策损失表。

  1. 根据最小错误率贝叶斯决策进行分类。
  2. 根据最小风险贝叶斯决策进行决策。

本2025 题2

给出 c1c_1c1​、c2c_2c2​ 和决策损失表，使用最小错误率和最小风险进行决策。

研2019 题1

进行贝叶斯决策，分别基于最小风险和最小方差进行决策。

研2024 题1

给出相关数据，分别根据最小错误率贝叶斯决策和最小风险贝叶斯决策进行计算。

研2025 题1

给出先验概率、类条件概率和决策损失函数 λ\lambdaλ。

  1. 使用最小错误率进行决策。
  2. 使用最小风险进行决策。

感知机准则

本2021 题1

使用感知机准则求判别函数。

本2023 题4

题干给出 x1,x2,x3,x4,a1,b1x_1,x_2,x_3,x_4,a_1,b_1x1​,x2​,x3​,x4​,a1​,b1​ 的值，且 x1,x2∈Ax_1,x_2 \in Ax1​,x2​∈A，x3,x4∈Bx_3,x_4 \in Bx3​,x4​∈B。使用梯度下降法求感知机准则函数，并给出 a,ba,ba,b 的最终值。

本2025 题3

使用感知机准则求判别函数。

研2023 题5

给出两个二维正样本、两个二维负样本，以及初始向量 a,ba,ba,b。学习率为 1，使用感知机准则进行迭代计算。

研2024 题5

给出两个二维正样本、两个二维负样本和初始权重向量，写出增广形式，并使用感知机准则写出所有迭代步骤和最终结果。说明梯度下降失效问题的原因及解决办法。

支持向量机 SVM

本2021 题5

介绍 SVM 模型，并说明核函数的作用。

本2023 题2

简述支持向量机（SVM）的原理，说明遇到噪声和线性不可分时应该如何解决。

本2025 题4

解释支持向量机 SVM 的思想，解释核函数的作用。

研2019 题3

说明 SVM 的基本思想、模型表达式、软间隔和硬间隔的物理含义，以及如何用 SVM 解决非线性问题。

研2020 题2

说明 SVM 的基本思路、模型公式、软间隔、硬间隔、如何处理离群点和噪声，以及如何处理非线性样本分类。

研2023 题2

说明支持向量机的原理、模型表达式，说明如何处理噪声和离群点，以及如何解决非线性问题。

研2025 题4

  1. 从几何解析的角度描述参数 www 和 bbb 的意义。
  2. 说明惩罚系数和松弛变量的作用。

决策树与 ID3

本2021 题6

给出 12 行数据和 3 个属性列，根据 ID3 算法构建一棵决策树，并说明决策树避免过拟合的两种方法。

本2023 题3

题干给出一张特征表。

  1. 使用 ID3 算法构造一个决策树，并使用构造的决策树判断一个实例的分类结果。
  2. 如何解决决策树的过拟合问题？简述一种解决办法的原理及其缺点。

本2025 题5

根据三种属性（口味：甜、咸、酸；温度：冷、热；分量：大、中、小）对 12 个样本构建 ID3 决策树，分析 ID3 的缺点，举出两种缓解过拟合的方法（预剪枝算法、后剪枝算法），并选择其中一种说明优劣。

研2019 题2

说明 ID3 和 C4.5 的区别，说明预剪枝和后剪枝的基本思想及优缺点。

研2019 题6

说明什么是过拟合，以及解决过拟合的方法。

研2020 题1

使用 ID3 算法构建决策树，对宇宙星球或近地卫星是否适合生存进行分类。另一份同年回忆版给出的近地卫星题干为：2077 年人类发射近地卫星，一共发射 800 颗，根据大小和轨道远近，有着不同的宜居条件（“是”表示宜居），表格如下。

数量 大小 轨道 是否宜居
30 大 远 是
130 大 近 是
48 小 远 是
161 小 近 是
20 大 远 否
170 大 近 否
11 小 远 否
230 小 近 否

构建一个 ID3 决策树，要求写出详细计算过程，并画出决策树，标出每个结点的正类、负类样本数量和分支结点对应的属性，并标出叶子结点最终属于哪个类别。

研2023 题4

第一问：使用 ID3 算法计算并构造一棵决策树。第二问：说明 ID3 算法的缺点，并列举改进算法。

研2024 题7

使用 ID3 算法手动构建一棵决策树。说明 ID3 算法的优缺点，以及如何改进。

研2025 题8

判断学生是否会加入算法竞赛集训队。题干给出 4 个属性：GPA（高、中、低）、感兴趣程度（高、一般、低）、时间（充足、一般、紧张）、编程能力（高、中、低）。

  1. 按照 ID3 流程生成决策树。
  2. 给定一个同学的属性，判断他是否会加入。
  3. 简述预剪枝和后剪枝的方法及优缺点。

研2025 题9

给定带有一个隐藏层的前馈全连接神经网络，隐藏层和输出层都有激活函数。

  1. 推导第一层和第二层参数 www 如何更新。
  2. 说明动量 SGD 和 Adam 如何解决陷入局部极值点或震荡的问题。
  3. 简述为什么会出现梯度消失，以及如何缓解这一现象。

K-means

本2021 题4

写出 K-means 算法，说明其不足，并写出它的一种改进。

本2023 题6

简述 K-means 算法原理。K-means 算法有什么缺点？给出一种改进方法。

本2025 题6

描述 K-means 算法流程，分析劣势并给出一种改进方法（K-means++）。

研2023 题7

给出 K-means 算法的基本流程。给出一个包含 10 个点的表格和 3 个中心点，使用 K-means 进行计算。

研2024 题4

介绍 K-means 模型，写出模型的计算过程。

研2025 题2

  1. 使用数学语言描述 K-means 的流程。
  2. 执行一遍 K-means 流程：给定 4 个二维点的坐标，初始化 2 个二维中心点，要求迭代执行 2 次。
  3. 说明 K-means 的缺陷以及解决办法（K-means++）。

PCA 与 LDA / Fisher 准则

本2021 题3

利用 PCA 算法将给定的五个二维向量降到一维。简述 PCA 算法和 LDA 算法的基本思想，并说明两者的区别。

本2023 题5

简述 PCA 和 LDA（Fisher 准则）的原理和区别。

研2019 题7

基于最小均方误差思想推导 PCA 算法，并写出计算步骤。

研2020 题6

写出主成分分析（Principal Component Analysis, PCA）的基本思想，并从最大方差思想推导其结果。

研2023 题6

基于最小均方误差推导 PCA 主成分分析，并给出 PCA 算法的基本流程。

研2024 题8

介绍 PCA，解释什么是基于最大方差和基于最小均方误差的思想，并从最大方差思想推导 PCA。掌握最大方差和最小均方误差的计算方法，能用数学语言描述和推导。

研2025 题3

  1. 简述最大方差、最小均方误差的主要思想。
  2. 写出 PCA 的一般求解过程，包括求协方差矩阵、最大特征值对应的特征向量等。
  3. 说明 PCA 与 LDA 的关系与区别。

集成学习

本2023 题7

本2025 题7

研2020 题3

说明集成学习的基本思想，并分别以串行化的 Boosting 和并行化的 Bagging 解释其原理。

研2023 题3

说明集成学习的原理，并介绍 AdaBoost 和 Random Forest 的串行、并行思想。

研2024 题6

说明集成学习的思想，介绍 Boosting 和 Bagging 两种方法，并说明模型的采样、结构和输出形式。

研2025 题7

  1. 叙述集成学习的思想。
  2. 简述 Boosting 和 Bagging 的执行流程。

深度学习与开放题

本2021 题8

谈谈机器学习在某领域的应用，如医疗、金融、电商、交通等。

本2023 题9

现如今购物 App 的推荐算法总是会根据用户的浏览记录，向用户推荐感兴趣的商品，使用户陷入“信息茧房”中。

  1. 如何使用机器学习优化产品业务？
  2. 从算法的角度，简述如何规避“信息茧房”。

本2025 题9

文生视频用到了什么技术？说明其可能的挑战和潜在问题。

研2019 题9

给出机器学习和深度学习的联系，说明二者各有什么优缺点，并谈谈你认为未来深度学习会如何发展。

研2020 题9

结合本课程内容谈谈你对深度学习的理解，说明深度学习模型存在什么问题，并谈谈你对深度学习未来发展方向的预测。

研2023 题9

结合所学内容，给出大模型的应用，以及大模型未来的挑战和方向。

研2024 题10

谈谈人工智能的潜在应用及挑战。

研2024(1) 题9

说明机器学习如何在大模型中应用。
